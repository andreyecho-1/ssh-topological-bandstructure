# 1D Su-Schrieffer-Heeger (SSH) Tight-Binding Band Structure Simulator

## Overview
This repository contains a computational physics script written in Python that calculates and visualizes the electronic band structure and topological phase transitions of the 1D Su-Schrieffer-Heeger (SSH) model using a tight-binding matrix Hamiltonian formulation.

## Physics Background
The SSH model is a foundational model in topological condensed matter physics describing electrons hopping on a 1D dimerized lattice with alternating intracell ($v$) and intercell ($w$) hopping amplitudes. 

The momentum-space Bloch Hamiltonian $H(k)$ is represented as:

$$H(k) = \begin{pmatrix} 0 & v + w e^{-ik} \\ v + w e^{ik} & 0 \end{pmatrix}$$

By diagonalizing $H(k)$ across the 1D Brillouin zone ($k \in [-\pi, \pi]$), we obtain the energy dispersion relation:

$$E(k) = \pm \sqrt{v^2 + w^2 + 2vw \cos(k)}$$

### Phase Regimes
* **Trivial Phase ($v > w$):** A bulk energy gap exists with normal band ordering.
* **Topological Phase ($v < w$):** The energy gap closes at $v = w$ and reopens into a non-trivial topological phase capable of hosting zero-energy edge states under open boundary conditions.
